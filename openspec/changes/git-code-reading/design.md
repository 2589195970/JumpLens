# 设计

## 共享语言能力

语法分析提供即时颜色，JDT LS 返回的 semantic tokens 叠加精确的类、方法、字段、参数与局部变量分类。语义响应绑定文本版本，过期响应丢弃。One Dark 和 IDEA 调色板同时用于 CodeMirror、只读预览与 Orca 主题贡献。

插件通过 contributes.syntaxes 为 .java 提供 TextMate 语法，使 Orca 原生源码与提交差异获得相同类别的基础高亮。原生差异的语义 token 注入不属于已公开宿主 API，JDT 语义叠加在 JumpLens 自有视图中提供。

## 提交阅读

新增 .jumplens-review 类型的未命名阅读页，通过标签栏新增菜单进入。阅读页首次绑定当前工作区，列出其中 Git 仓库。用户选择仓库和提交后，左侧为第一父提交，右侧为选定提交；根提交左侧为空。重命名保留两侧路径，删除和新增允许一侧为空，合并提交与第一父提交比较。

文件内容只通过 Git 对象读取；编辑器两侧只读。版本身份包含仓库绝对路径、完整 commit、仓库内路径与左右侧。Git 调用使用参数数组；路径来自已选提交的文件清单。

## 历史分析

导航与语义分析按需准备指定提交的源码缓存。缓存只写入插件缓存目录，忽略符号链接和非源码文件，限制文件数和总大小。缓存键为仓库与 commit，完成标记在所有文件写完后生成。同版本工程单独启动语言服务，结果以只读源码预览展示；工作区当前文件和语言服务文档不被替换。

## 验证

覆盖语义 token 解码、过期响应、配色分类、根提交、重命名、删除、多仓库和历史文件已在工作区消失等行为。运行既有单元测试、类型检查、插件验证与编辑器检查，在 Orca 中检查真实 Java 提交的类和方法颜色及历史预览。
